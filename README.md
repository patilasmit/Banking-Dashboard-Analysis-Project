# 📊 UK Bank Customer Dashboard – Power BI Project

This project presents a **UK Bank Customer Dashboard** created using **Power BI**.  
It provides a holistic view of customer demographics, financial balances, job classifications, and regional distribution.  
The goal of this project is to **practice Power BI skills** while extracting **business insights** from customer data.

---

## 🔹 Key Features
- **Total Customers:** 4,014
- **Average Age:** 38.6 years (Range: 15–64)
- **Gender Distribution:** Male (53.9%) | Female (46.1%)
- **Job Classification:** White Collar (1.96K) | Blue Collar (1.05K) | Other (1.01K)
- **Balance Analysis:** Majority have balances < 50,000
- **Regional Spread:** England, Scotland, Wales, Northern Ireland

---

## 📊 Dashboard Highlights
1. **Balance Buckets** – Shows customer distribution across financial ranges.  
2. **Age & Gender** – Analyzes customer demographics.  
3. **Regional Map** – Identifies where customers live.  
4. **Job Classification Tree Map** – Segments customers by profession.  
5. **KPIs** – Quick insights into customer count and average age.
